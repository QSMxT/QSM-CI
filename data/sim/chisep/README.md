# χ-separation phantom (qsm-forward)

Susceptibility source-separation dataset: methods are fed the local field, R2′, χ_total and
multi-echo magnitude, and must recover the paramagnetic (χ+) and diamagnetic (χ−) source maps.

## Layout

- `inputs/` — provided to the method: `localfield.nii.gz` (ppm), `r2prime.nii.gz` (Hz),
  `chimap.nii.gz` (χ_total, ppm), `magnitude.nii.gz` + `phase.nii.gz` (4D multi-echo GRE),
  `se_magnitude.nii.gz` (4D multi-echo spin-echo, magnitude only), `mask.nii.gz`, `params.json`
  (GRE `TE`/`B0`/…, plus `se_TE`/`se_TR`). Field-based methods (χ-sepnet, SUSEP-Net) use local field +
  R2′ + QSM; GRE-based methods (APART-QSM, DECOMPOSE) opt into the raw multi-echo `phase`/`magnitude`
  and do their own field mapping / QSM; the spin-echo is optional — its magnitude decays with R2 (not
  R2*), so a method can estimate R2′ = R2* − R2 itself from the GRE/SE pair rather than using the
  provided R2′, or feed the SE to a model that requires it.
- `groundtruth/` — scored against: `chi-para.nii.gz` (χ+), `chi-dia.nii.gz` (χ−, stored as a positive
  magnitude), plus `chimap.nii.gz` and `dseg.nii.gz`.

## R2′ relaxivity model

R2′ uses source- and orientation-dependent relaxivities (Ridani et al. 2026):

```
R2' = Dr₊ · |χ+| + Dr₋(θ) · |χ−|
```

Paramagnetic sources use a spherical relaxivity Dr₊; diamagnetic (myelin) sources use a cylindrical
relaxivity Dr₋(θ) ∝ sin²θ, where θ is the fibre-to-B0 angle from the diffusion V1 eigenvector. In the
static-dephasing regime (Yablonskiy & Haacke 1994), reversible relaxation depends on the magnitude of the
field perturbation, not its sign. The absolute magnitude is set by `--dr-model` (see *Provenance /
regenerating* below): `fixed` anchors Dr₊ = 137 Hz/ppm (Shin et al. 2021), field-independent; `scaled`
uses the static-dephasing magnitudes Dr₊ = 107.84·B0, Dr₋ = 133.77·sin²θ·B0. The default `fixed` at 7T
gives Dr₊ = 137 and Dr₋ = 170·sin²θ Hz/ppm.

To rebuild `r2prime.nii.gz` from the ground-truth sources and the shipped `dr-pos`/`dr-neg` maps:
`Dr₊·|chi-para| + Dr₋·|chi-dia|` within the brain mask.

## Provenance / regenerating

This dataset implements the Ridani et al. (2026) Susceptibility-Separation-Phantom on the QSM
Challenge 2.0 head model, generated by [`scripts/gen_chisep.py`](../../../scripts/gen_chisep.py):
χ⁺/χ⁻ built per tissue with R1/R2\*-modulation and per-tract WM anisotropy (from the diffusion V1
eigenvector), then R2′/field/GRE signal (7T, 4 echoes [4,12,20,28] ms, 1 mm, `peak_snr=100`, `seed=42`).

```bash
~/repos/qsm/qsm-forward/venv/bin/python scripts/gen_chisep.py --out data/sim/chisep   # full sim (compute node)
~/repos/qsm/qsm-forward/venv/bin/python scripts/gen_chisep.py --maps-only             # cheap χ+/χ-/R2' check
```

`gen_chisep.py` also flattens the output into the QSM-CI artifact layout; the phantom itself can be
generated directly with qsm-forward (≥ 0.31): `qsm-forward chi-sep <data-dir> <bids-dir>` (`--dr-model`,
`--isotropic`, `--no-brain-mask` mirror the flags above).

**Relaxivity (Dr), `--dr-model`.** Both models share the orientation-dependent sin²θ shape and differ
only in magnitude. `fixed` (default): paramagnetic relaxivity anchored at Dr⁺ = 137 Hz/ppm (Shin et al.
2021), field-independent, with R2′ magnitudes consistent with in-vivo χ-separation calibrations.
`scaled`: the static-dephasing relaxivities of Yablonskiy & Haacke (1994) as in Ridani et al.
(Dr⁺ = 107.84·B0, Dr⁻ = 133.77·sin²θ·B0 Hz/ppm), which scale linearly with field. The χ⁺/χ⁻ ground
truth is identical for both; only R2′ and the signal decay scale differ. `--isotropic` disables
anisotropy. Validate any phantom with
[`scripts/validate_phantom.py`](../../../scripts/validate_phantom.py) before scoring; re-score methods
whenever regenerated.

## Differences from the reference phantom

The χ⁺/χ⁻ construction and white-matter anisotropy (including the reference's R1-weighted noise texture,
here seeded for reproducibility) match Ridani et al. Two aspects differ:

1. **Dr magnitude.** Default `--dr-model fixed` (Dr⁺ = 137 Hz/ppm, Shin et al. 2021) rather than the
   reference's field-scaled static-dephasing value (Dr⁺ ≈ 755 Hz/ppm at 7 T). The χ⁺/χ⁻ ground truth is
   unchanged; only R2′ and the signal magnitude differ. `--dr-model scaled` matches the reference.
2. **Brain masking.** χ (and therefore the field and phase) is restricted to the brain mask, so the
   simulated data carries no background field from skull/air. The reference simulates the whole head;
   `--full-head` reproduces that (background field, whole-head χ).

Implementation note (numerically near-equivalent, not a design change): R1/R2* are denoised with
PyWavelets rather than MATLAB `wavedec3`.
